# UI Polish: Animations, Confetti & Dark Mode

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add message entrance animations, milestone confetti celebrations, and a system-wide dark mode toggle to improve the feel of the app.

**Architecture:** CSS keyframe animations on message bubbles (no JS animation library needed). `canvas-confetti` for lightweight celebration effects triggered on first conversation completion. Dark mode via Tailwind's `dark:` variant with a `ThemeProvider` context that persists preference to `localStorage` and applies a class to `<html>`.

**Tech Stack:** Tailwind CSS 4 `dark:` variants, CSS `@keyframes`, `canvas-confetti` (2KB, zero-dep)

- [ ] **Step 3: Create `ThemeProvider.tsx`**

```tsx
'use client';

import { createContext, useContext, useEffect, useState } from 'react';

type Theme = 'light' | 'dark';

const ThemeContext = createContext<{
  theme: Theme;
  toggleTheme: () => void;
}>({ theme: 'light', toggleTheme: () => {} });

export const useTheme = () => useContext(ThemeContext);

export default function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<Theme>('light');

  useEffect(() => {
    const stored = localStorage.getItem('theme') as Theme | null;
    if (stored) {
      setTheme(stored);
      document.documentElement.classList.toggle('dark', stored === 'dark');
    }
  }, []);

  const toggleTheme = () => {
    const next = theme === 'light' ? 'dark' : 'light';
    setTheme(next);
    localStorage.setItem('theme', next);
    document.documentElement.classList.toggle('dark', next === 'dark');
  };

  return (
    <ThemeContext value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext>
  );
}
```

### Task 5: Confetti Celebrations

**Files:**
- Install: `canvas-confetti`
- Modify: `src/components/ChatPage.tsx`

Confetti triggers on two occasions:
1. **Conversation milestones** — 1st, 10th, 25th, 50th, 100th (then every 100th) completed conversation
2. **Knowledge creation** — First time Claude saves to the knowledge base in a given conversation (once per conversation)

Milestone count comes from the DB via `/api/conversations` (already fetched by the sidebar). Knowledge confetti uses a ref to track per-conversation.

- [ ] **Step 1: Install canvas-confetti**

```bash

```

- [ ] **Step 2: Add confetti triggers to ChatPage**

In `ChatPage.tsx`, add import at top of file:


Add a ref to track whether knowledge confetti already fired this conversation. Inside the component, near the other state declarations:

Add `useRef` to the existing React import:

```tsx

```

Reset the ref when starting a new conversation. In `handleNewChat` (around line 152), add:

```tsx

```

Also in `loadConversation` (around line 62), add:

```tsx

```

**Milestone confetti:** In the `handleSend` function, inside the `if (event.type === 'done')` block (around line 238), after `setRefreshTrigger((prev) => prev + 1);`, add:

```tsx
// Confetti on conversation milestones (1, 10, 25, 50, 100, 200, ...)
const res = await fetch('/api/conversations');
const convs = await res.json();
const count = convs.length;
const milestones = [1, 10, 25, 50];
if (milestones.includes(count) || (count >= 100 && count % 100 === 0)) {
  confetti({ particleCount: 100, spread: 70, origin: { y: 0.6 } });
}
```

Note: this fetch is cheap — the sidebar already refreshes from the same endpoint on `refreshTrigger` change. The `done` event fires once per conversation so this is at most one extra call.

**Knowledge confetti:** In the `if (event.type === 'tool_use')` block (around line 224), add before the `setToolStatus` call:

```tsx
if (event.tool === 'mcp__knowledge__save_knowledge' && !knowledgeConfettiFired.current) {
  knowledgeConfettiFired.current = true;
  confetti({ particleCount: 50, spread: 60, origin: { y: 0.7 }, colors: ['#fbbf24', '#f59e0b', '#d97706'] });
}
```

The knowledge confetti uses gold/amber colors to visually distinguish it from milestone confetti.
